# rn-currency — 리포트 포맷 · 저장

조회(SKILL.md §0~§4)가 끝난 뒤에만 필요하다. 아래 `§N`은 SKILL.md의 절 번호다.

## 포맷

실행 날짜는 `date +%F`(Bash)로 확보해 상단에 박는다.

```
RN 최신성 점검 — <YYYY-MM-DD>   (스코프: core/lib/platform, 대상 N개)
스냅샷: RN <x.y.z> · React <x.y.z> · New Arch <on/off> · targetSdk <NN> · iOS min <NN.n>
권장 요약: 승격 <N>건 · 유지 <M>건(soak <a> / churn <b> / RN상한 <c> / known issue <d>) · major 점프 <K>건

🔴 Urgent
- [대상] 현재 vX → **권장 vZ** | 최신 vY (<권장 아닌 사유 + 해제 시점>) | gap 요약 | 영향 | 권장 조치 | 근거: <릴리즈 노트·정책 링크>
🟠 Deadline
- [대상] 현재 vX → **권장 vZ** | 최신 vY (...) | gap 요약 | **기한: <날짜 또는 제거 예정 버전>** | 영향 | 권장 조치 | 근거: <링크>
🟡 Recommended
- [대상] ...
⚪ Optional
- [대상] ...

확인 못 함 (webfetch 실패·정보 불명확):
- [대상] — 사유
```

- 권장 = 최신이면 `→ **권장 vZ** (=최신)`로 축약한다. 권장 = 현재면 `→ **유지(현재)**` + 사유. 어느 쪽이든 **사유 자리를 비우지 않는다**.
- lockstep 세트는 **한 줄에 묶는다**(`[Reanimated + worklets] 4.3.1/0.7.0 → 권장 4.3.3/0.7.2`). 따로 쓰면 짝 하나만 올리는 사고가 난다.
- **0건인 등급은 섹션 자체를 생략**한다. 빈 헤더를 남기지 않는다.
- `확인 못 함`은 0건이어도 `없음`으로 남긴다. 조회가 전부 성공했다는 사실 자체가 정보이고, 생략하면 "빠뜨린 것"과 구분되지 않는다.

## 저장

화면 출력으로 끝내지 않고 **이 스킬 폴더에 파일로 남긴다** — `.claude/skills/rn-currency/reports/<YY.MM.DD>.md`(예 `26.07.30.md`). 내용은 위 포맷 그대로, 첫 줄만 H1(`# RN 최신성 점검 — <YYYY-MM-DD>`)로 올린다.

- **날짜는 위 `date +%F` 출력 하나에서만 파생한다.** 파일명(`26.07.30`)과 본문 헤더(`2026-07-30`)가 어긋나면 안 된다 — 실측 사례가 있다(파일명 `26.07.30` · 본문 `2026-07-26`, 이전 리포트를 rename만 한 흔적). **rename으로 날짜를 갱신하지 마라.** 갱신하려면 다시 실행해 새로 쓴다.
- 같은 날 재실행이면 **덮어쓴다.** 스코프를 좁혀 돌렸어도 파일을 쪼개지 않는다 — 헤더의 스코프 줄이 그 사실을 담는다.
- **쓰기는 메인만, `Write` 1회.** 서브에이전트는 §2 잠금대로 read-only — 조회 결과만 반환한다.
- 직전 리포트가 있으면 **델타 표기용으로만 읽는다**: 새로 생긴 gap·해소된 gap·등급이 바뀐 항목, 그리고 **지난번 `유지`가 이번에 승격으로 풀렸는지**(soak 만료·회귀 픽스 도착)를 헤더 아래 한 줄로. **판정 근거로 재활용하지 않는다** — 지난 리포트는 stale이고 근거는 이번 실행의 registry·노트 조회에서 다시 나와야 한다.
- AGENTS.md "명시 요청 없이 새 파일·문서 생성 금지"의 **명시적 예외**다. 예외 범위는 이 리포트 파일 하나 — 그 외 파일 생성은 여전히 금지.
